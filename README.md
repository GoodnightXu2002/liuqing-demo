# 柳青画庄 · 非遗工坊数字化交付样板

面向非遗工坊/老字号的数字化服务交付样板：市场调研 → 产品定义 → Web 可交互原型 → AI 素材管线 → 上线运维 SOP。

**在线演示：https://goodnightxu2002.github.io/liuqing-demo/**

## 亮点

- 单页可交互原型：首页 / 商品 / 详情 / 体验预约 / 个人中心
- **单配置文件换皮**：品牌、门店、商品、体验项目、横幅文案全部收敛在 `config.js`，交付新客户只改一个文件
- 传统版式 + AI 生成素材：年画锦鲤形象经 v0–v5 多轮迭代，AI 联名商品与活动横幅由 AI 产出
- 纯静态、无后端依赖，可任意静态托管

> 本仓库为 Web 演示端；微信小程序双端原型见交付源码。
